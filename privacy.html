So linha · Privacy policy

Last updated: October 11, 2026

So linha is the private publishing tool of the YouTube channel “So…”. It runs only on the channel owner's own computer and is used only by him, to manage his own channel.

What data the app accesses

When the owner signs in with Google, So linha asks permission to use the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API on his channel. With that permission it:

  • uploads the channel's videos and sets their title, description, thumbnail and publishing time;
  • reads the list of the channel's videos and their status;
  • reads the channel's own statistics (views, watch time, impressions and similar reports).

How the data is used and stored

  • The data is used only to publish the channel's videos and to show the owner how they perform.
  • The sign-in token and the statistics are stored only on the owner's computer. Nothing is sent to any server other than Google's own APIs.
  • No data is sold, shared with third parties, used for advertising, or used to train any model.
  • So linha's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access and delete data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops the app from reaching the channel. The owner can also delete the stored token and statistics from his computer at any time.
